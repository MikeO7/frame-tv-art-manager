## 2026-06-08 - Function Extraction State Loss Risk
**Learning:** When extracting deeply nested logic into a new helper function (like pulling `rewriteImage` out of `OptimizeFile`), it is extremely dangerous to attempt to re-evaluate conditions (like recreating the `needsAdjustment` check manually) inside the new helper rather than simply passing the already-calculated parent state as a boolean argument. Hallucinating the logic inside the helper almost always leads to subtle functional drift and breaks the original execution paths.
**Action:** Always explicitly pass existing, pre-computed state variables as arguments to newly extracted helper functions rather than trying to reconstruct the logic internally.
