Running in minutes

One container.
One required setting.

Point the service at your Frame TV, mount a data directory, and approve the first connection with your remote.

Read the complete installation guide →
compose.yaml
services:
  frame-tv-art-manager:
    image: ghcr.io/mikeo7/frame-tv-art-manager:latest
    restart: unless-stopped
    environment:
      TV_IPS: "192.168.1.150"
    volumes:
      - ./data:/data
$ docker compose up -d

Compatibility

Made for modern Samsung Frame TVs.

The current target is Samsung Frame hardware running Tizen 8.0 or newer. Because Samsung’s private Art Mode protocol varies between models and firmware releases, other versions may work but are not the primary target.

Common questions

Before you connect your Frame.

Can it automatically upload art to a Samsung Frame TV?

Yes. It regularly compares your local collection with the user-managed artwork on each configured TV and uploads missing images over the local network.

Do I need SmartThings or a Samsung cloud account?

No. The manager talks directly to the TV on your LAN using its Art Mode protocol. The first connection requires approval on the TV.

Will it delete artwork already on my TV?

By default, it removes only artwork it owns and tracks. Unknown TV artwork is preserved unless you explicitly enable the destructive removal option.

Can it prepare portrait photos for a 4K Frame TV?

Yes. Portrait images can be cropped, padded, or combined into a collage, then resized to the configured display dimensions.

Can I run it on a NAS or home server?

Yes. Docker Compose is the simplest deployment, and the container is suitable for a Linux home server or compatible NAS that can reach the TV on the local network.
