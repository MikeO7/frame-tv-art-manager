Samsung Frame TV automation guide

How to automatically upload art to a Samsung Frame TV

Short answer: run Frame TV Art Manager on a home server, point it at a folder of JPEG or PNG images, and provide the TV’s local IP address. It prepares the images and synchronizes missing artwork with the TV on a schedule.

Samsung’s SmartThings workflow is useful for occasional manual uploads. It becomes repetitive when artwork changes often, when several televisions need the same collection, or when a NAS or home server already holds the source images. Frame TV Art Manager turns that manual workflow into a durable synchronization process.

What the automation does

A sync cycle reads the complete local artwork collection, validates and prepares each image, observes the current Art Mode inventory on every configured TV, uploads missing files, and removes only manager-owned files that are no longer in the desired collection.

What you need

  • A Samsung Frame TV reachable on the same local network.
  • Samsung Frame hardware running Tizen 8.0 or newer, which is the project’s current target.
  • A Linux home server, NAS, mini PC, or Mac capable of running Docker or the Go binary.
  • A stable IP address for each television.
  • JPEG or PNG artwork.

How automatic Frame TV art sync works

1. Treat a local folder as the desired collection

Files placed in the artwork directory are what the manager should maintain on every configured television. Removing a local file tells the manager it is no longer part of the desired collection. Control files, hidden files, temporary files, JSON, YAML, and symlinks are excluded from the artwork catalog.

2. Prepare artwork for the display

Supported images are decoded and validated before use. When a transform is needed, the manager can orient, crop or pad, resize, sharpen, convert supported color profiles to sRGB, and produce the configured output size. The default is 3840×2160. Portrait images can be cropped, padded, or paired into landscape collages.

3. Connect directly over the local network

The service uses the TV’s private Art Mode protocol. The television displays an Allow/Deny prompt on the first connection; approving it returns a pairing token that is stored locally. A Samsung cloud account is not involved.

4. Reconcile on a schedule

The first sync starts when the service starts. Later cycles run according to SYNC_INTERVAL_MINUTES, which defaults to 30 minutes. Unchanged images are not needlessly uploaded again.

Why the safety model matters

Artwork synchronization can become destructive if an incomplete folder scan or unreachable TV is mistaken for an empty collection. Frame TV Art Manager is designed to fail closed: an incomplete source resolution is not accepted as a trustworthy collection, unknown TV state cannot authorize deletion or display-changing work, and transient failures retain last-known-good art.

By default, artwork already on the TV that is not owned by the manager is preserved. The separate REMOVE_UNKNOWN_IMAGES option changes that rule and must be enabled explicitly.

Can it sync more than one Samsung Frame TV?

Yes. TV_IPS accepts a comma-separated list of television addresses. Each TV is observed and reconciled independently against the same committed collection snapshot, and pairing state is stored per television.

Can it find artwork automatically?

Yes. In addition to local files and browser uploads, the manager can resolve configured images from Unsplash, NASA, the Art Institute of Chicago, Pexels, Pixabay, and direct HTTP or HTTPS URLs. Provider failures are conservative: an incomplete result does not authorize pruning previously downloaded source artwork.
