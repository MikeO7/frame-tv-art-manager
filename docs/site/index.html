For Samsung The Frame owners with a NAS or home server

Keep a folder of art synced to Samsung Frame TV.

Frame TV Art Manager is a self-hosted service that prepares your JPEG and PNG files, then reconciles manager-owned art across one or more Tizen 8+ Frame TVs over your local network.

Folder-to-TV workflow

Update the folder. Let the service handle the repeat uploads.

01

Add photos and artwork

Use a local JPEG or PNG folder, the authenticated upload endpoint, or an optional configured artwork provider.

02

Prepare files for the display

Images that need transformation are oriented, cropped or padded, and resized. The default output is 3840×2160; dimensions are configurable.

03

Reconcile every configured TV

The service observes each TV, uploads missing files, and removes obsolete manager-owned art only when the required state is trustworthy.

What makes it useful

Built for recurring synchronization, not one-off uploads.

The differentiator is the reconciliation state: the manager knows which TV art it owns, preserves unknown art by default, and refuses destructive work when the collection or TV observation is incomplete.

↻

One collection for multiple TVs

TV_IPS accepts one or more addresses. Each TV is reconciled independently against the same committed collection snapshot.

4K

Display preparation by default

Optimization is enabled by default with orientation, crop or padding, color handling, sharpening, and 3840×2160 output. Smart crop is optional and off by default.

LAN

Direct TV connection

Local-only collections require no Samsung cloud account. Remote providers and the optional HTTP crop provider use external network access only when configured.

+

Several ways to supply art

Use a folder, authenticated browser uploads, Apple Photos workflows, Unsplash, NASA, Art Institute of Chicago, Pexels, Pixabay, or direct URLs.

✓

Preserves evidence before it changes the TV

Unknown TV artwork is preserved by default. An empty desired collection keeps the final known-good managed item, and transient source failures retain the previous source collection.

A good fit when

You already run something at home.

  • You have a NAS, Unraid or Synology system, mini PC, Mac, or Linux server.
  • Your Frame TV targets Tizen 8.0 or newer and is reachable on the LAN.
  • You update a photo or art folder regularly, or maintain more than one TV.
  • You want unattended inventory sync rather than repeating a phone upload flow.

Know before installing

This is a home-server service.

You need a stable TV address, persistent /data storage, LAN reachability, and one approval on the television. SmartThings is likely simpler for occasional manual uploads.

The project targets Tizen 8+. Other firmware may work, but Samsung’s private Art Mode protocol varies by model and release.

Common questions

What the service does—and deliberately does not do.

Can it automatically upload art to a Samsung Frame TV?

Yes. Frame TV Art Manager regularly compares a committed artwork collection with each configured TV and uploads missing manager-owned images over the local network.

Do I need SmartThings or a Samsung cloud account?

No for a local-only collection. The manager talks directly to the TV on your LAN. Configured remote artwork providers still contact their external services.

Will it delete artwork already on my TV?

By default it removes only artwork it owns and tracks. Unknown TV artwork is preserved unless REMOVE_UNKNOWN_IMAGES is explicitly enabled.

Does it change the artwork currently displayed?

No. The manager preserves the current artwork selection because the private TV protocol does not provide the recoverable selection state required for a safe automatic change.

Can it prepare portrait photos for a 4K Frame TV?

Yes. Portrait images can be cropped, padded, or combined into a collage. The default output is 3840×2160, and the dimensions are configurable.

Can I run it on a NAS or home server?

Yes. Docker Compose is the simplest deployment for a Linux home server or compatible NAS that can reach the TV on the local network.
