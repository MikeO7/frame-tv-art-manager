AI art with MCP

Make AI art for your Samsung Frame TV with Claude or ChatGPT (MCP)

Short answer: Frame TV Art Manager has a built-in MCP endpoint, off by default, that lets your own AI assistant build art collections for your Samsung Frame TV. The assistant makes the images with its own tools; the manager holds no AI keys and calls no AI service. It tells the assistant the screen's exact size and format, stores and checks each image, previews how it will be fitted, puts it in a themed collection, schedules it, and syncs it to the TV. Turn it on with MCP_ENABLED=true and an MCP_TOKEN of at least 24 characters, then connect Claude Code, Claude Desktop, or another MCP client.

What MCP is

The Model Context Protocol (MCP) is an open standard that lets an AI assistant use tools provided by other programs. A program that speaks MCP, called a server, lists its tools with their names, inputs, and purpose, and the assistant decides when to call them during a conversation. Frame TV Art Manager is an MCP server: when you ask your assistant for a Christmas collection, it calls the manager's tools to read the TV's display spec, add the images, and set the dates.

Why the manager needs no AI keys

The images come from your assistant, under your own account with it. Frame TV Art Manager never calls an AI service and stores no AI credentials. Its job is everything that happens after an image exists:

  • Telling the assistant what the TV needs: 3840×2160 by default, 16:9, sRGB, JPEG or PNG, the size limit, and how other shapes are cropped or matted.
  • Storing each image after checking it is a real JPEG or PNG, and recognizing duplicates by their contents.
  • Showing a preview of each picture exactly as it will be prepared for the TV.
  • Putting the pictures in a themed collection, scheduling it, and starting a sync.

If your assistant can't make images, it can still search public-domain museum collections, or add images from https links you give it.

Set it up in four steps

  1. Make a token

    Run openssl rand -hex 24 and keep the result. The token must be at least 24 characters with no spaces.

  2. Turn on the endpoint

    Add MCP_ENABLED and MCP_TOKEN to the container's environment, as below, and run docker compose up -d.

  3. Connect your assistant

    Add the server to Claude Code or Claude Desktop with the commands below, or to any MCP client that supports streamable HTTP.

  4. Check the connection

    Ask "What does my Frame TV need from an image?" The assistant should call get_display_spec and answer with the screen's size.

The endpoint is http://<server-address>:8080/mcp (port HEALTH_PORT, which must stay on), and every request must send Authorization: Bearer <MCP_TOKEN>. While MCP_ENABLED is off, the address returns 404.

Claude Code

claude mcp add --transport http frame-tv http://<server-address>:8080/mcp \
  --header "Authorization: Bearer <MCP_TOKEN>"

Claude Desktop

Claude Desktop connects through the mcp-remote bridge, which needs Node.js. Add this to claude_desktop_config.json and restart Claude Desktop:

{
  "mcpServers": {
    "frame-tv": {
      "command": "npx",
      "args": ["mcp-remote", "http://<server-address>:8080/mcp", "--allow-http",
               "--header", "Authorization:${FRAME_TV_AUTH}"],
      "env": { "FRAME_TV_AUTH": "Bearer <MCP_TOKEN>" }
    }
  }
}

Use https:// and drop --allow-http when the manager is behind a TLS proxy.

ChatGPT and other MCP clients

Other clients use the streamable HTTP transport with the URL and header above. Whether an assistant can connect depends on two things: its MCP support must let you send the Authorization header, and it must be able to reach your server. Claude Code and Claude Desktop run on your computer, so they reach a server on your home network. An assistant that connects from its own cloud servers, rather than from your computer, can't reach a home-network address; it would need the endpoint exposed behind a TLS reverse proxy (see Keep it safe). Check your assistant's current documentation before exposing anything.

The tools your assistant gets

MCP tools provided by Frame TV Art Manager
ToolWhat it does
get_display_specThe target size (3840×2160 by default), aspect ratio, formats, size limit, and how pictures that don't fit are cropped or matted, with prompt tips
search_public_domain_artSearches the Art Institute of Chicago, The Met, the Cleveland Museum of Art, and SMK for public-domain works
add_artworkStores one JPEG or PNG (an https link or base64 data) in a collection, creating the collection if needed, and records its title, artist, license, and link
preview_artworkShows a 960×540 preview of a picture exactly as it will be prepared for the TV; nothing is saved
list_artworkLists stored pictures with their collections, whether today's rules show them, and which TVs hold them
list_collections, create_collection, update_collection, delete_collectionManage collections and their schedules
remove_from_collectionTakes a picture out of a collection
sync_nowStarts a sync now instead of waiting for the next one
get_statusThe last sync's result and each TV's state

Example: a Christmas collection

This is how a typical request plays out, shortened. Your assistant's wording will differ; the tool calls are the same.

You: Make me 12 Christmas paintings in the style of Dutch winter landscapes and show them Dec 1 to Jan 6.

Assistant calls get_display_spec, learns the screen is 3840×2160 and 16:9, and generates 12 landscape images with its own image tool, in one painterly style, with no text or frames.

Assistant calls add_artwork once per image with the collection Christmas, a title, and the prompt as the description. The first call creates the collection, which starts off and exclusive.

Assistant calls preview_artwork to check how the pictures will be fitted, then update_collection with the schedule window, 12-01 to 01-06, and finally sync_now and get_status.

Assistant: The Christmas collection is scheduled from December 1 to January 6. Until then it stays hidden. On December 1 it replaces your everyday art, and on January 7 your everyday art comes back.

You: Add a few real winter paintings too.

Assistant calls search_public_domain_art for "winter", lists candidates with their title, artist, museum, and license, and adds the ones you pick with add_artwork, using each result's image link, license, and museum page.

The window opens at midnight in LOCATION_TIMEZONE (UTC by default), so set it to your own time zone. The seasonal collections guide explains schedules, exclusive and everyday art, and what happens on a full TV.

Prompt tips for a matte art screen

The Frame's anti-reflection matte panel makes paintings look like paintings, but it is still a lit screen in your living room. get_display_spec hands your assistant these tips, and they work just as well in your own prompts:

  • 16:9 landscape, highest resolution. Ask for a landscape composition at the highest resolution your image model supports, ideally exactly 3840×2160. Anything smaller than about 2560×1440 is visibly enlarged on a 4K screen. Keep the main subject away from the edges.
  • Painterly and textured. Oil, gouache, watercolor, etching, and woodcut styles look most like real art on the matte screen; glossy photoreal renders look like a TV.
  • Muted palettes, soft light. Avoid large pure-white or neon areas: they glow in a dark room at night.
  • No text, frames, or watermarks. Leave out text, signatures, watermarks, borders, frames, and mats; the TV and the manager add their own.
  • One style per set. Keep the style and palette the same across a collection so it feels curated.
A snowy Dutch canal at dusk with skaters and a windmill, painted in oil
with visible brushwork, muted blues and warm lamplight, 16:9 landscape,
no text, no signature, no frame.

Images that aren't exactly 16:9 are still handled: with the default settings, a landscape image fills the screen when that crops away at most 25% and needs no more than 3× enlargement; otherwise it is shown whole on a gallery mat. preview_artwork shows exactly which. See the art size guide for the details.

What the assistant can't do

  • Delete image files. Removing a picture from a collection, or deleting a collection, leaves the files in the folder.
  • Put a picture on screen right now. There is no "show this picture now" tool; the TV changes only through the normal sync and the scheduled picture changes, with all of their safety checks.
  • Fetch from your home network. Links must be https and point to the public internet; private addresses are refused, even after redirects.
  • Get around the upload rules. Images must be JPEG or PNG, no larger than MAX_DOWNLOAD_SIZE_MB (20 MB by default), and are checked and deduplicated before they are kept.
  • Change anything during a dry run. With DRY_RUN=true the read-only tools still work, and tools that would change anything are refused.

Most assistants hand over generated images as links, so image_url is usually the practical choice; base64 data works for smaller images.

Keep it safe

  • Off by default. Nothing listens at /mcp until you set MCP_ENABLED=true and a token.
  • Treat the token like a password. Anyone with it can add art, change collections and their schedules, and start a sync, though not delete image files. Use a long random token, such as the output of openssl rand -hex 24.
  • Keep it on your home network. If you expose the endpoint beyond it, put it behind a reverse proxy with TLS; the token is sent with every request. Never forward port 8080 from your router.
  • Guessing is slowed down. Wrong tokens count toward the same per-address limit as upload passwords, and browser requests from other websites are refused.

Questions people ask

Do I need an OpenAI or Anthropic API key to make AI art for my Frame TV?

Not for Frame TV Art Manager. It holds no AI keys and calls no AI service. Your assistant makes the images under your own account with it, and the manager sizes, previews, schedules, and syncs them.

Which AI assistants work with Frame TV Art Manager?

Claude Code, Claude Desktop through the mcp-remote bridge, and other MCP clients that support streamable HTTP with an Authorization header and can reach your server. An assistant that connects from its own cloud servers needs the endpoint exposed behind a TLS reverse proxy.

Can the AI assistant delete my photos or change what's on screen?

No. No tool deletes image files, and there is no tool to show a picture right away. The TV changes only through the normal sync and the scheduled picture changes, with their safety checks.

What size should AI-generated art be for The Frame?

A 16:9 landscape, ideally exactly 3840×2160 pixels, as JPEG or PNG. Anything smaller than about 2560×1440 is visibly enlarged on the 4K screen.

Can my assistant use real paintings instead of AI images?

Yes. The search_public_domain_art tool searches the Art Institute of Chicago, The Met, the Cleveland Museum of Art, and SMK for public-domain works, and add_artwork records each one's title, artist, license, and museum link.
