Samsung Frame TV automation guide

How to automatically upload art to a Samsung Frame TV

Short answer: run Frame TV Art Manager on a NAS or home server, point it at a folder of JPEG or PNG images, and provide the TV’s local IP address. It prepares files when needed and reconciles missing manager-owned art on a schedule.

Samsung’s SmartThings workflow is useful for occasional manual uploads. It becomes repetitive when artwork changes often, when several TVs need the same collection, or when a NAS or home server already holds the source images. Frame TV Art Manager turns that repeated upload task into a maintained synchronization process.

What the automation does

A sync cycle reads a complete collection snapshot, validates and prepares each image, observes the Art Mode inventory on every configured TV, uploads missing files, and removes obsolete manager-owned files only when the required state is trustworthy. It preserves the artwork currently selected on the TV.

What you need

  • A Samsung Frame TV reachable on the same local network.
  • Samsung Frame hardware running Tizen 8.0 or newer, which is the project’s current target.
  • A Linux home server, compatible NAS, mini PC, or Mac capable of running Docker or the Go binary.
  • A stable IP address for each TV and persistent storage for artwork, pairing tokens, and reconciliation state.
  • JPEG or PNG artwork.

How automatic Frame TV art sync works

1. Treat a local folder as the desired collection

Files in the artwork directory are what the manager should maintain on every configured TV. Removing a local file normally makes its manager-owned TV copy eligible for removal on a later safe cycle. Control files, hidden files, temporary files, JSON, YAML, and symlinks are excluded from the artwork catalog.

The default policy does not reduce the managed TV collection to zero: if the desired collection becomes empty and no successor is bound, the final known-good manager-owned item is preserved.

2. Prepare artwork for the display

Supported images are decoded and validated before use. When a transform is needed, the manager can orient, crop or pad, resize, sharpen, convert supported color profiles to sRGB, and produce the configured output size. The default is 3840×2160. Portrait images can be cropped, padded, or paired into landscape collages.

Optimization is enabled by default. Smart crop and museum treatment are separate optional controls and are disabled by default.

3. Connect directly over the local network

The service uses the TV’s private Art Mode protocol. The television displays an Allow/Deny prompt on the first connection; approving it returns a pairing token stored under the persistent data directory. A local-only collection does not require a Samsung cloud account.

4. Reconcile on a schedule

The first cycle starts with the service. Later cycles run according to SYNC_INTERVAL_MINUTES, which defaults to 30 minutes. Unchanged images are not needlessly uploaded again.

Why the safety and deletion rules matter

Artwork synchronization can become destructive if an incomplete folder scan or unreachable TV is mistaken for an empty collection. Frame TV Art Manager fails closed: incomplete source resolution is not accepted as a trustworthy collection, unknown TV state cannot authorize deletion or display-changing work, and transient failures retain last-known-good art.

By default, artwork already on the TV that is not owned by the manager is preserved. The separate REMOVE_UNKNOWN_IMAGES option changes that rule and must be enabled explicitly. Dry-run mode does not pair, persist tokens, upload, delete, wake a TV, or change the display.

The manager also preserves the currently displayed artwork. Automatic selection is disabled until the private protocol exposes an observable, recoverable selection postcondition.

Can it sync more than one Samsung Frame TV?

Yes. TV_IPS accepts a comma-separated list of TV addresses. Each TV is observed and reconciled independently against the same committed collection snapshot, and pairing state is stored per TV.

Can it find artwork automatically?

Yes. In addition to local files and authenticated browser uploads, the manager can resolve configured images from Unsplash, NASA, the Art Institute of Chicago, Pexels, Pixabay, and direct HTTP or HTTPS URLs.

Those integrations contact external services. Downloaded images remain in the local artwork directory until the operator removes them; deleting a source entry does not automatically delete files it downloaded. If a provider fails during a cycle, the previous source collection is retained instead of being pruned from an incomplete result.

Start automatic artwork sync

Use the Docker Compose setup, approve the television once, and add images to the persistent artwork directory.
