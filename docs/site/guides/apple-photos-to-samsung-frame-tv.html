iPhone, iPad, and Mac uploads

Sync Apple Photos to Samsung Frame TV

Short answer: enable Frame TV Art Manager’s authenticated upload endpoint, convert HEIC photos to JPEG when necessary, and send favorites or album images from an iPhone Shortcut, a Mac export, or curl. Uploaded files join the persistent artwork collection and sync on a later cycle.

This workflow is useful when Apple Photos is where you already choose favorites or maintain albums, but a NAS or home server runs Frame TV Art Manager. The upload path stays between your device and the server on your network. Your Photos library may still use iCloud depending on your Apple setup; Frame TV Art Manager does not control that.

How the Apple Photos upload workflow works

  1. Your iPhone, iPad, or Mac sends an authenticated JPEG or PNG to POST /upload.
  2. The manager validates the image, calculates an exact byte digest, and saves it under a safe generated filename in the persistent artwork directory.
  3. An identical upload is deduplicated.
  4. On the next synchronization cycle—30 minutes by default—the image is prepared to the configured target and reconciled with each TV.

Uploaded files are durable user-owned artwork. They remain in the local collection until you remove them from the artwork directory.

Method 1: iPhone or iPad Shortcut

Create a Shortcut that finds the photos you want, repeats over the results, converts each image to JPEG, and sends the converted file to your server’s upload URL.

  1. Add Find Photos and filter by Favorite, an album, or another selection that matches your workflow.
  2. Limit the number of results while testing.
  3. Add Repeat with Each.
  4. Inside the loop, add Convert Image and choose JPEG. This avoids sending HEIC, which is not an accepted upload format.
  5. Add Get Contents of URL, use http://SERVER-IP:8080/upload, select POST, and send the converted image as the request body or file.
  6. Add an Authorization header containing HTTP Basic credentials for frame:UPLOAD_TOKEN.

Apple occasionally changes labels and layout in Shortcuts. The required behavior is stable even when the exact control names move: select images, convert to JPEG, repeat, and POST each file with Basic authentication.

After the Shortcut works manually, you can run it from a personal automation. Whether iOS can run without a confirmation prompt depends on the selected trigger and current operating-system behavior.

Method 2: export favorites or an album from a Mac

A Mac can export selected Photos content to a temporary directory and upload the JPEG files. One option is the third-party osxphotos command-line tool, which requires access to the local Photos library.

Replace --favorite with an album selector if you maintain a dedicated Frame TV album. A scheduler such as launchd can run the script later, but test the export and authentication interactively first.

How uploaded Apple Photos are processed and removed

The upload handler accepts JPEG and PNG files within the configured size limit. It validates the content, deduplicates exact bytes, and writes a safe hash-based name. On a later cycle, normal image settings apply: orientation, configured portrait handling, crop or padding, color conversion, sharpening, and target sizing. The default target is 3840×2160; it is configurable.

Smart crop is optional and disabled by default. If you configure the external HTTP crop provider, a maximum-512-pixel JPEG preview may be sent to the service you selected.

To remove an uploaded photo, delete its file from the persistent artwork directory. On a later safe cycle, the manager can remove the corresponding manager-owned TV art. If the desired collection becomes empty, the default safety policy preserves the final known-good managed item.

Security notes

  • The upload endpoint is disabled by default and requires a token of at least 16 characters.
  • HTTP Basic authentication does not encrypt the token or image. Keep plain HTTP on a trusted LAN or put the endpoint behind TLS.
  • Do not expose the upload port directly to the public internet.
  • Uploaded bytes become persistent artwork. Review available storage and remove files you no longer want.
  • Use a separate high-entropy upload token rather than reusing another password.
