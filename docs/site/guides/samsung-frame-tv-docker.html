Docker Compose installation

Run a Samsung Frame TV art manager with Docker

Short answer: deploy the GHCR container with the TV’s local IP in TV_IPS and a persistent /data volume. Approve the first connection on the TV, then add JPEG or PNG files to data/artwork.

Docker Compose is the simplest way to run Frame TV Art Manager continuously on a Linux server, mini PC, or compatible NAS. The container packages the Go service and image-processing dependencies while the persistent data directory holds artwork, pairing tokens, and reconciliation state.

Minimal Docker Compose configuration

TV_IPS is the only required environment variable for basic local-folder operation. A working installation also needs persistent storage, a stable TV address, LAN reachability, and first-connection approval on the television.

Publishing port 8080 exposes the health and status endpoints. It does not enable uploads by itself; the upload endpoint remains disabled until UPLOAD_ENABLED=true and a valid UPLOAD_TOKEN are configured.

Installation steps

  1. Give the Samsung Frame TV a stable LAN address through a DHCP reservation or equivalent router setting.
  2. Replace 192.168.1.150 with that address.
  3. Run docker compose up -d.
  4. When the TV shows an Allow/Deny prompt for “Frame Art Manager,” choose Allow with the remote.
  5. Place .jpg, .jpeg, or .png files in data/artwork.

Which data must be persistent?

Persistent data paths used by the container
PathPurposeWhy persistence matters
/data/artworkDesired artwork collection and its private manifestIt is the durable source of truth for synchronization.
/data/tokensPairing tokens and per-TV reconciliation stateLosing it can require pairing again and removes the manager’s ownership evidence.

Mounting the complete /data directory, as in the example, preserves both locations across container upgrades. Losing token state can make previously uploaded art indistinguishable from unknown TV art.

Does Docker need host networking?

No in the documented setup. The container connects to a known TV IP and only needs a route that can reach the television. Network isolation, VLANs, or firewall rules must permit the TV connection.

The service targets Samsung Frame hardware running Tizen 8.0 or newer. Other firmware may work, but the private Art Mode protocol varies between models and releases.

Running on Synology, Unraid, or another NAS

A NAS is suitable when it can run the container and reach the TV’s LAN address. Preserve the data mount and ensure the container account can write to it. If bind-mount ownership is a problem, pre-create data/artwork and data/tokens, then use the documented PUID/PGID or rootless-container approach.

Monitoring the container

The service exposes /live for process liveness, /ready and /health for readiness after a successful cycle, and /status for current and per-TV synchronization information.

The container image healthcheck calls the application’s -livenesscheck command, which checks /live. A failed Docker healthcheck does not restart a container by itself; restart behavior is controlled by Docker or the orchestrator.

Safe configuration for a first run

Set DRY_RUN=true when you want to observe the collection and TV plan without persistent local mutation, pairing, uploads, deletions, Wake-on-LAN, or display changes. Keep REMOVE_UNKNOWN_IMAGES=false unless you deliberately want the manager to remove TV artwork it does not own.

What should I know about browser and Apple Photos uploads?

Uploads are disabled by default. Enabling them requires UPLOAD_ENABLED=true and an UPLOAD_TOKEN of at least 16 characters. Authentication uses HTTP Basic with username frame.

Keep plain HTTP on a trusted LAN. HTTP Basic authentication does not encrypt the token or image. Use a TLS reverse proxy before making the endpoint reachable across an untrusted network.
