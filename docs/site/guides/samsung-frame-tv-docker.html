Docker setup

Install Frame TV Art Manager with Docker

Short answer: run the ghcr.io/mikeo7/frame-tv-art-manager:latest image with your Samsung Frame TV's IP address in TV_IPS and a ./data:/data volume. Approve the connection once on the TV, then copy JPEG or PNG files into data/artwork. The image runs on amd64, arm64, and armv7, so it fits a NAS, a mini PC, a Raspberry Pi-class board, or a Mac.

By MikeO7Published July 26, 2026Last updated November 7, 2026

Before you start

  • A Samsung Frame TV running Tizen 8.0 or newer, on the same network as the server.
  • Docker with Compose on a machine that stays on.
  • Access to your router, to give the TV a fixed address.

Install in six steps

  1. Give the TV a fixed IP address

    In your router, create a DHCP reservation so the Frame always gets the same address. The TV shows its current address under its network settings.

  2. Create the compose file

    Make a folder for the service and save the compose.yaml below in it, with your TV's address.

  3. Start the container

    Run docker compose up -d, then docker compose logs -f frame-tv-art-manager to watch it connect.

  4. Approve it on the TV

    With the TV on, an Allow/Deny prompt named "Frame Art Manager" appears. Choose Allow with the remote. You only do this once.

  5. Add pictures

    Copy .jpg, .jpeg, or .png files into data/artwork. Each file is replaced by its prepared version, and the untouched original is kept in the hidden data/artwork/.frame-tv-art-manager/originals folder.

  6. Check that it worked

    Open http://SERVER-IP:8080/status. Your TV should be listed with status ok, and the pictures appear in Art Mode.

docker compose up -d
docker compose logs -f frame-tv-art-manager

Folders and permissions

Everything lives in the /data volume:

  • /data/artwork is your collection. Mount a different host folder here if your art lives elsewhere, for example /volume1/photos/frame:/data/artwork.
  • /data/tokens holds the TV's pairing token and the record of what was uploaded. Keep it across upgrades, or the TV will ask to pair again and existing uploads will be treated as yours.

If the container can't write to ./data, create the folders with mkdir -p data/artwork data/tokens. Set PUID and PGID to control file ownership, or own the folders yourself, add user: "UID:GID", and leave PUID/PGID unset.

Settings you'll likely want

Common settings (all optional except TV_IPS)
SettingDefaultPurpose
TV_IPSrequiredTV address, or several separated by commas
SYNC_INTERVAL_MINUTES30Time between syncs
PORTRAIT_MODEpadPortraits on a gallery mat; or collage, crop
ROTATION_INTERVAL_DAYS14How long each piece stays on a full TV
MATTE_STYLEnoneSamsung matte for every upload
UPLOAD_ENABLED, UPLOAD_TOKENoffWeb and iPhone Shortcut uploads
ARTWORK_SOURCES_FILEunsetDownload art from museums, Wikimedia Commons, NASA, and photo sites
MCP_ENABLED, MCP_TOKENoffLet an AI assistant add and schedule art over MCP; the token needs at least 24 characters (AI art guide)
LOCATION_TIMEZONEUTCClock for power times, sun-following brightness, and seasonal collection dates
MAX_LOCAL_FILE_SIZE_MB200Largest file accepted from the artwork folder (1–512); larger files are skipped with a warning
DRY_RUNfalsePlan without changing anything

Every setting, with comments, is in .env.example. On/off settings accept true/false, 1/0, yes/no, on/off, or y/n in any case. Anything else, an unknown log level, or a bad TV address stops the service at startup with a clear error, so a typo can't silently turn a setting such as DRY_RUN off.

Optional TV controls

  • Slideshow: SLIDESHOW_ENABLED, SLIDESHOW_INTERVAL (3, 15, 60, 720, or 1440 minutes), SLIDESHOW_TYPE (shuffle or sequential).
  • Brightness: a fixed BRIGHTNESS on the Frame's Art Mode scale of 0 to 10, or SOLAR_BRIGHTNESS_ENABLED=true with your latitude, longitude, and time zone to follow the sun between BRIGHTNESS_MIN and BRIGHTNESS_MAX (also 0 to 10). Values from 11 to 50, from the 0 to 50 scale earlier releases documented, are converted (30 becomes 6) with a warning; anything else outside 0 to 10 stops startup.
  • Nightly power-off: AUTO_OFF_TIME=22:00 turns off TVs showing art and leaves TVs in use alone.
  • Morning power-on: AUTO_ON_TIME (for example 07:00) together with TV_MAC wakes a single TV once a day, on the first sync in the AUTO_ON_GRACE_HOURS window (default 2), only if the TV is confirmed off or has dropped off the network; never when its state is unknown. TV_MAC on its own no longer wakes the TV. The magic packet goes to 255.255.255.255 and the TV's /24 broadcast address; set TV_WOL_BROADCAST to use one other broadcast address instead. Wake-on-LAN is a broadcast, which Docker's default bridge network doesn't pass to your LAN, so it needs network_mode: host.

If you leave these unset, the manager doesn't touch the TV's own settings.

Monitoring and upgrades

  • GET /live: the process is running (used by the container healthcheck).
  • GET /ready and /health: 200 once the last sync succeeded, otherwise 503.
  • GET /status: per-TV status, last error, rotation details, and credits for downloaded artwork as JSON. source_warning appears when an artwork source failed; the TVs still sync the art already on disk.

When UPLOAD_TOKEN is set, /status shows the last error and TV addresses only to requests signed in as frame with that token. Without credentials it returns the same fields with TVs numbered tv-1, tv-2, …, no error text, and "redacted": true.

Logs are structured JSON. To upgrade, run docker compose pull and docker compose up -d; your data folder carries over. Never expose port 8080 to the internet; keep it on your home network or behind a TLS reverse proxy.

Running without Docker

Build a single binary with the Go version in go.mod:

go build -o frame-tv-art-manager ./cmd/frame-tv-art-manager
TV_IPS=192.168.1.150 ARTWORK_DIR="$PWD/data/artwork" TOKEN_DIR="$PWD/data/tokens" ./frame-tv-art-manager
