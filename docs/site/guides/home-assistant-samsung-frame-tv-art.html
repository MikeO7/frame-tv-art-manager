Home Assistant

Home Assistant and Samsung Frame TV art

Short answer: Home Assistant is good at controlling the TV; Frame TV Art Manager is good at keeping its art collection in sync. Run the art manager as its own Docker container on your network, watch it from Home Assistant with a REST sensor on /status, and send pictures to it from automations with the upload endpoint. Everything stays local; no SmartThings cloud is involved.

By MikeO7Published November 6, 2026Last updated November 7, 2026

Frame TV Art Manager is not a Home Assistant integration or add-on. It's a separate service that works well alongside one.

Why keep Frame art local

Home Assistant can reach a Samsung TV in two ways: locally over the network, or through Samsung's SmartThings cloud. In June 2026 Samsung announced paid SmartThings API access, with a US$4.99-a-month personal plan and free access ending after the third quarter of 2026. Frame TV Art Manager talks to the TV directly over your network, so its art sync doesn't depend on SmartThings at all.

Install it next to Home Assistant

If Home Assistant runs in Docker, add Frame TV Art Manager to the same host with the compose file from the Docker guide. If you use Home Assistant OS, run Frame TV Art Manager on another always-on machine, such as your NAS. The two only need to reach each other and the TV over the network.

Watch sync health with a REST sensor

The /status endpoint returns JSON with last_sync_ok, last_error, and a tvs object with each TV's status, image count, and rotation details. Add this to configuration.yaml:

rest:
  - resource: http://SERVER-IP:8080/status
    scan_interval: 300
    authentication: basic
    username: frame
    password: !secret frame_upload_token
    sensor:
      - name: Frame art last sync OK
        value_template: "{{ value_json.last_sync_ok }}"
      - name: Frame art last error
        value_template: "{{ value_json.last_error | default('', true) | truncate(250) }}"

The three sign-in lines matter once UPLOAD_TOKEN is set: /status then shows the last error and TV addresses only to requests signed in as frame with that token, and anonymous requests get the same fields with TVs numbered tv-1, tv-2, …, no error text, and "redacted": true. Put the token in secrets.yaml as frame_upload_token. Without UPLOAD_TOKEN, /status is open and the sign-in lines are harmless.

Then alert yourself when last_sync_ok stays false. A source_warning field appears when an online art source failed; the TVs still sync the art already on disk. /ready returns HTTP 200 or 503 if you'd rather use a simple binary check; it needs no password.

Send pictures from an automation

Turn on the uploader (UPLOAD_ENABLED=true and a 16-character-plus UPLOAD_TOKEN). Home Assistant's shell_command can then post a JPEG or PNG, for example a snapshot saved by another automation:

# configuration.yaml
shell_command:
  send_to_frame: "/config/scripts/send_to_frame.sh {{ filename }}"
#!/bin/sh
# /config/scripts/send_to_frame.sh (chmod +x); the token lives in a file only root can read
TOKEN="$(cat /config/.frame_upload_token)"
curl --fail -u "frame:$TOKEN" -F "file=@/config/www/frame/$1" http://SERVER-IP:8080/upload

Keep the token out of configuration.yaml, and only pass simple file names you control. Uploads are handled one at a time; a second upload sent at the same moment gets HTTP 429 and should be retried.

Avoid two tools fighting over the TV

  • Frame TV Art Manager changes the picture on screen every 15 minutes by default. If a Home Assistant automation picks the art, set SLIDESHOW_ENABLED=false, or the two will keep replacing each other's choice.
  • Brightness and power settings are left alone unless you set them. If Home Assistant already manages them, leave the matching settings unset.
  • It never deletes art it didn't upload, so pictures you push another way stay on the TV.
  • Each tool that connects to the TV may need its own one-time Allow on the TV. Use a clear CLIENT_NAME so you know which prompt is which.

Questions people ask

Can Home Assistant control Samsung Frame TV Art Mode?

Home Assistant's Samsung integrations can control power and, with some community integrations, parts of Art Mode. For keeping a collection of art on the TV, Frame TV Art Manager runs alongside Home Assistant and handles uploads, preparation, and rotation.

Does Frame TV Art Manager need SmartThings?

No. It connects to the TV directly on your local network, so Samsung's SmartThings API changes don't affect it.

Is there a Home Assistant add-on for Frame TV Art Manager?

No. It runs as a standalone Docker container. Home Assistant OS users can run it on another machine such as a NAS.

How do I know if the Frame art sync failed?

Poll http://SERVER-IP:8080/status with a REST sensor and watch last_sync_ok, or check /ready, which returns 503 when the last sync failed.
