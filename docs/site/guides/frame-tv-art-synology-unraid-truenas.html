Synology, Unraid, TrueNAS

Samsung Frame TV art from a Synology, Unraid, or TrueNAS NAS

Short answer: Frame TV Art Manager is a small Docker container, so any NAS that runs containers can keep your Frame in sync. On Synology use Container Manager's Projects, on Unraid add a container from the Docker tab, and on TrueNAS install a custom app from YAML. In each case you set TV_IPS, map a folder to /data, and approve the connection once on the TV.

By MikeO7Published November 6, 2026Last updated November 6, 2026

The same three things on every NAS

  1. A fixed IP for the TV, using a DHCP reservation in your router.
  2. A persistent folder mapped to /data. It holds artwork (your collection) and tokens (the pairing token and upload records). You can map your art share straight to /data/artwork instead.
  3. The right owner for files, set with PUID and PGID so you can still edit the artwork share over SMB.

Originals are kept. Each picture in the artwork folder is replaced by its prepared 3840×2160 version, and the untouched original is saved in the share’s hidden .frame-tv-art-manager/originals folder. Allow about as much extra space as the pictures you add.

Synology DSM (Container Manager)

  1. Install Container Manager from Package Center (DSM 7.2 or later).
  2. In File Station, create docker/frame-tv-art-manager with data/artwork and data/tokens inside it.
  3. Open Container Manager, go to Project, choose Create, pick that folder as the path, and choose to create a docker-compose.yml.
  4. Paste the compose file below, set your TV's address, and add PUID/PGID for the DSM user who owns the share. Running id yourname over SSH shows them; DSM users usually belong to group 100 (users).
  5. Finish the wizard to build and start the project, then approve the prompt on the TV.
  6. Copy pictures into docker/frame-tv-art-manager/data/artwork from File Station or over SMB.

Unraid (Docker tab)

  1. Open the Docker tab and choose Add Container.
  2. Set Repository to ghcr.io/mikeo7/frame-tv-art-manager:latest and a name such as frame-tv-art-manager.
  3. Add a Path: container path /data, host path /mnt/user/appdata/frame-tv-art-manager. To use an existing share for art, add another path from /mnt/user/your-art-share to /data/artwork.
  4. Add a Variable TV_IPS with your TV's address, plus PUID=99 and PGID=100, Unraid's usual nobody:users owner for shares.
  5. Add a Port mapping 8080 to 8080 if you want the status page or uploader.
  6. Apply, then approve the prompt on the TV.

If you prefer compose files, the Compose Manager plugin accepts the same file as the Docker guide.

TrueNAS SCALE / Community Edition

  1. Create a dataset, for example apps/frame-tv-art-manager, with data/artwork and data/tokens folders.
  2. Go to Apps, then Discover Apps, and choose Install via YAML from the menu (TrueNAS 24.10 and later use Docker for apps).
  3. Paste the compose file below with the host path changed to your dataset, such as /mnt/tank/apps/frame-tv-art-manager/data:/data.
  4. Set PUID/PGID to the user that owns the dataset; TrueNAS's built-in apps user is 568.
  5. Save, then approve the prompt on the TV.

Compose file for any NAS

services:
  frame-tv-art-manager:
    image: ghcr.io/mikeo7/frame-tv-art-manager:latest
    container_name: frame-tv-art-manager
    restart: unless-stopped
    environment:
      TV_IPS: "192.168.1.150"        # your TV's address; comma-separate several
      CLIENT_NAME: "Frame Art Manager"
    ports:
      - "8080:8080"
    volumes:
      - ./data:/data

Add PUID and PGID under environment for your NAS. QNAP Container Station, OpenMediaVault, Portainer, and anything else that accepts a compose file work the same way.

Raspberry Pi, mini PC, or Mac

The image is built for amd64, arm64, and armv7, so a Raspberry Pi-class board, an Intel or AMD mini PC, or a Mac running Docker all work. Preparing a 24-megapixel photo uses roughly 250 MB of memory, and each picture stays within a 512 MB budget by default (IMAGE_MAX_WORKING_MEMORY_MB).

Network checklist

  • The NAS and the TV must reach each other: same network, or routing between VLANs.
  • Nothing needs to be opened to the internet. Keep port 8080 on your home network.
  • Wake-on-LAN (TV_MAC) is a broadcast that Docker's default bridge network doesn't forward, so it usually needs host networking.
